## 2. 작성 규칙

- H1은 `번호. 한국어 문서명` 형식으로 쓴다.
- H2는 `번호. 한국어 섹션명` 형식으로 쓴다.
- 같은 레벨의 헤더는 같은 문장 패턴을 사용한다.
- 문서 본문은 한국어를 기본으로 쓰되, 제품 역할명과 시스템 용어는 필요한 경우 English term을 유지한다.
- 컬렉션, API, DB 필드처럼 구현 세부사항은 합의 전까지 개념 문서에 넣지 않는다.

## 3. 용어 기준

- `정책`: 브랜드가 지향하거나 지켜야 하는 상위 기준
- `룰`: 정책을 실제 작업에 적용할 수 있게 낮춘 판단 단위
- `점검`: 룰을 작업물이나 입력값에 적용해 확인하는 행위
- `피드백`: 점검 결과를 사용자가 고칠 수 있게 설명한 것
